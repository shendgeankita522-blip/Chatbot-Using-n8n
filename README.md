## 📌 Project Overview

This project showcases the development of an AI chatbot using **n8n Workflow Automation**. The workflow is designed to receive user messages, process them using AI, and return intelligent responses through an automated pipeline.

The project demonstrates workflow automation, AI integration, and chatbot development using a visual workflow builder.

## 🚀 How to Use

1. Clone this repository.

```bash
git clone https://github.com/your-username/AI-Chatbot-using-n8n.git
```

2. Open **n8n**.

3. Import the workflow file located in:

```
workflow/chatbot_using_n8n.json
```

4. Configure your API credentials if required.

5. Save and execute the workflow.

6. Start chatting with the AI chatbot.
